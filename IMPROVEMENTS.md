## 2. New CLI Flags in `train.py`

| Flag | Default | Notes |
|------|---------|-------|
| `--alpha` | `0.0` | Prior-loss weight. **Fixed 0.0 for Tables 1–6**; swept for Figure 3. |
| `--prior` | `none` | Prior-loss form: `none` / `paper-phi-only` / `legacy`. See §3. |
| `--dish_init` | `avg` | CONET coefficient init: `avg` (paper default) / `norm` / `uni`. |
| `--features` | `M` | `M` = multivariate (Tables 2–6); `S` = univariate (Table 1). |
| `--figure3` | flag | Append one row to `results/figure3_runs.csv`. |
| `--gpu` | `0` | GPU device id. |
| `--affine` | `1` | RevIN affine (1 = enabled, 0 = disabled). |

The `results/figure3_runs.csv` schema is:

```
dataset, seq_len, pred_len, model, norm, alpha, seed,
MSE, MAE, RMSE, MAPE, MSPE, dish_init, scaled, prior, features, timestamp
```

## 3. Prior-Loss Implementation

The paper's theoretical loss is

```
Loss = MSE(ŷ, y) + α · MSE(phi_h, mean_of_true_future_window)
```

The second term peeks at the future (the true mean is not available at
inference), so it is an ablation only. Three modes are supported via `--prior`:

| `--prior` | Behaviour | Used for |
|-----------|-----------|----------|
| `none` (default) | No prior loss; matches official open-source Dish-TS. | **All Tables 1–6**. |
| `paper-phi-only` | HoriCoNet's φ_h is supervised by `(φ_h − true_future_mean)²`. | **Figure 3** alpha sweep. |
| `legacy` | The forecast mean is pulled toward φ_h (an earlier, harmful variant). | Debugging / comparison only. |

Core code in `train.py`:

```python
if args.norm == 'dishts' and args.alpha > 0:
    phih = unify_model.nm.phih                  # HoriCoNet output
    true_future_mean = y[:, -args.pred_len:].mean(dim=1, keepdim=True)
    if args.prior == 'paper-phi-only':
        prior_loss = ((phih - true_future_mean) ** 2).mean()
    elif args.prior == 'legacy':
        prior_loss = ((forecast.mean(dim=1, keepdim=True) - phih) ** 2).mean()
    else:
        prior_loss = 0.0
    loss = loss + args.alpha * prior_loss
```
